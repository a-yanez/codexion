# Description
Codexion is a project which introduces the students of 42 to the concept of concurrency. Concurrency means that multiple processes can start, run and be completed in overlapping time periods. This means that several tasks can be done independently (or semi independently) and, depending on the CPUs characteristics, even parallely. For this project a variation of the *dining philosophers* problem is simulated, using coders and USB dongles instead of spaguetti and forks.

## The dining philosophers
The dining philosophers problem is an example problem used in concurrent algorithm design to illustrate synchronization issues and techniques for resolving them.
